# Troy Homebrew Tap

Homebrew formula for [Troy](https://github.com/avirajkhare00/troy) — fine-tune
LLMs on your MacBook with one YAML file. https://gettroy.app

## Install

```bash
brew tap avirajkhare00/troy https://github.com/avirajkhare00/troy-homebrew
brew install troy
```

## Usage

```bash
troy doctor   # check your Mac
troy init     # create a config
troy train    # fine-tune
```

Requires an Apple Silicon Mac (M1 or later).
